# LeetCode 50 Days DSA Java Challenge

🚀 **My 50 Days DSA Challenge** — Solving one LeetCode problem daily in Java.

This repository contains my daily practice for **Data Structures and Algorithms (DSA)**. The goal is to strengthen problem-solving skills and improve coding efficiency by tackling different problems every day.

## Repository Structure
leetcode-50-days-java/
├─ README.md
├─ LICENSE
├─ .gitignore
├─ solutions/
│ ├─ Day01_TwoSum.java
│ ├─ Day02_AddTwoNumbers.java
│ └─ 

- `solutions/` — Contains each LeetCode problem solution as a separate Java file.
- Each file is named in the format: `DayNN_ProblemName.java` (e.g., `Day01_TwoSum.java`).
- Each file includes:
  - Problem description
  - Difficulty level
  - Approach and explanation
  - Quick `main()` method to test the solution
